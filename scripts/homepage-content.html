First clear: Warrior or Paladin

Choose Warrior if you prefer a durable melee approach, or Paladin if you want area coverage with shields and self-healing. Their forgiving starting points help you learn escape routes before chasing a damage ranking. Keep moving even when your health looks comfortable.

Ranged pressure: Hunter or Warlock

Hunter suits players who want distance and pet pressure while repositioning. Warlock rewards damage over time and demon synergies as the run develops. Neither choice excuses an empty escape route: establish area coverage before investing everything in a boss-damage plan.

Precise positioning: Mage or Rogue

Mage offers an area-damage approach with less room for positioning errors. Rogue emphasizes burst and deliberate circling around enemies. Consider either after you can recognize a closing wave and move before it surrounds you. A strong damage window helps only if you survive to use it.

What is Azeroth Survivors?

Azeroth Survivors puts familiar Warcraft-inspired classes and places into a survivors-style loop. Enemies close in, abilities attack automatically, and level-up choices shape how you handle the next wave. Your practical tasks are movement, collecting experience and choosing upgrades that solve the problem in front of you. Early success comes from keeping room to move while turning the wave into experience.

This is a fan project by Aethus, separate from the World of Warcraft client. This website is also independent: it provides written help and the class finder above. The game runs at the developer’s entry point. Open that page when you are ready to play; use this page to choose an approach and prepare your first decisions.

How to play Azeroth Survivors: your first run

  1. Open the developer’s page. Start at Aethus’s Azeroth Survivors website. Its current entry screen identifies WebGPU as a requirement and points players toward current Chrome, Edge or Safari. A browser name alone does not confirm your graphics hardware is compatible.
  2. Let loading finish. First visits may need more time to fetch resources. Keep the tab open while it makes progress. If the page reports that too many people are playing, treat that message as a capacity issue rather than repeatedly changing graphics settings.
  3. Focus the game and learn movement. Click inside the game area before testing keyboard input. Read the current controls and your starting ability. Move toward open ground, collect experience when an escape path remains available, and avoid getting trapped against a dense pack.
  4. Make the first upgrades solve wave pressure. An area tool helps when ordinary enemies accumulate. Once the wave is manageable, invest in a focused damage plan. Read each card’s actual effect instead of treating its color as proof it fits your build.

Before restarting after a loss, identify what ended the attempt: slow wave-clear, being surrounded or missing a boss opening. Change one decision on the next run so the result teaches you something. The first-run walkthrough expands this process into a checklist.

Azeroth Survivors builds: a practical three-phase plan

Use these phases as a planning framework, not a guarantee that every version, zone or draft follows the same clock. Check the current game’s spell text and boss warnings. If enemies already overwhelm your damage, solve that immediate problem before following a planned upgrade order.

Opening: build reliable area coverage

In roughly the first three minutes, favor a way to clear ordinary enemies while moving. Blizzard, Volley, Consecration, Rain of Fire and Chain Lightning are examples discussed in our guides. Choose from the cards actually offered; waiting for an ideal combination can leave you with no working answer to the wave.

Middle: strengthen one carry and cover one weakness

During the next part of the run, commit ranks to the attack doing most of your useful clearing. Add a survival tool that addresses your problem, such as movement, a shield or control. Use available rerolls when an unsuitable hand blocks that commitment, rather than spending them simply because the button is ready.

Later: improve the plan already working

As slots fill, compare carry upgrades and cooldown benefits before adding another unrelated spell. Against a boss, keep a route out of danger and use the attack openings you can safely maintain. Read the complete build priorities for passives, or use the class tier list as a qualified alpha snapshot.

Keep class choice separate from draft quality. A familiar character with useful gear can be a better learning tool than a highly ranked class you have never played. Compare attempts in the same zone where possible, note the spells you ranked, and look for repeatable improvements rather than judging everything from one unusually lucky hand.

Azeroth Survivors FAQ

Is Azeroth Survivors free, and is this the official website?

The game is a free fan project by Aethus. This is an unofficial guide, with no affiliation to Aethus or Blizzard Entertainment. Use the developer’s website for the game itself and its current distribution links.

Which class should I choose as a beginner?

Start by comparing Warrior and Paladin for a forgiving melee run, or Hunter if ranged positioning suits you. Use the class finder above to choose an approach. Practice and existing progression matter more than chasing a small tier difference.

Can I use this page before opening the game?

Yes. Filter the class recommendations, read the first-run steps and compare the build phases here. The tool needs no account and sends no character data. When ready, follow the labelled developer link to start the actual game.

Why will the browser version not start?

Read the message first. Missing WebGPU, graphics problems, unfinished loading and server capacity require different responses. Check the browser guidance above before reinstalling anything or clearing storage that may contain progress.

Are tier rankings and exact timings permanent?

No. Alpha balance, zone rules and available cards can change. Treat class rankings and the three-phase clock as guide snapshots. The current in-game descriptions and developer announcements take priority when they disagree with a guide.
